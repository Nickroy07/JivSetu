# Jivsetu Security Roadmap

1. Authentication/authorization: prototype foundation included.
2. Consent: case-taking, voice, document/OCR, sharing, revocation, audit.
3. Data protection: MySQL, private document storage, encryption, signed temporary access.
4. Audit: access, upload, OCR, edit, export, consent, admin actions.
5. AI privacy: minimization, controlled inputs, output validation, no autonomous diagnosis.
6. Federated Learning: local-training simulation now; real FL, secure aggregation and differential privacy later.
7. Production: TLS, secrets manager, rate limiting, security testing, backups, penetration testing and formal compliance review.
